# Profile artwork

The light and dark hero banners in this directory are original artwork created for Krishnam Murarka's GitHub profile.

- Canvas: 1280 × 420 SVG
- Direction: executive engineer; products, systems, operations and evidence
- Palette: graphite and slate with restrained emerald and blue accents
- External fonts, images, scripts and remote dependencies: none
- Accessibility: the profile README supplies visible-context alt text; each SVG also contains a title and description

Keep both theme variants structurally aligned when revising the artwork. Exported SVGs should remain script-free, self-contained and below 100 KB each.
